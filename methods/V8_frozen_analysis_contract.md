# V8 预冻结分析合同

冻结日期：2026-09-01（查看三项新增分析结果之前）。基线为 V7 交叉审计稿；V7 原件不覆盖。

## 科学问题与替代解释

主要问题是：冻结的 8 基因混合标志模块与 T 细胞比例的关系，是否超出表达量、检出率和 T/NK/ILC 谱系特异性相当的随机模块所产生的组成相关；类器官中经 QC 调整后出现的 SCD–VPS72 负相关依赖谱，能否在独立 2D DepMap CRC 细胞系中复制；独立全细胞 CRC 单细胞队列能否复现“全肿瘤混合模块随 T 细胞组成变化、上皮区室限制后衰减”。

替代解释包括：模块仅是普通免疫或 T 细胞标志组合；SCD–VPS72 关系由筛选质量或共同必需性轴驱动；单细胞相关由细胞组成而非细胞内状态产生。零假设为上述新增验证均不支持超出这些技术或组成解释的证据。

## 三项预设分析

### 1. GSE178341 匹配随机模块

- 生物学重复为患者（n 由 V7 冻结样本流确定），不使用细胞级 P 值。
- 每个候选基因按全肿瘤平均表达、细胞检出率和 TNKILC 相对其余肿瘤细胞的谱系特异性进行三维匹配。
- 排除冻结 8 基因和预设胞啃面板，避免把近义构件重新抽入零分布。
- 以 k=50 最近邻、10,000 个无放回模块为主要分析；k=25 和 k=100 为敏感性分析。
- 每个随机模块与冻结模块使用完全相同的患者级 log2-CPM、基因内标准化和均值评分方法。
- 主要统计量为与作者注释得到的 T-cell fraction 的 Spearman ρ；报告经验单侧和双侧 P 值、零分布 95% 区间和观察值百分位。

### 2. DepMap 26Q1 SCD–VPS72 复制

- CRC 2D 细胞系为独立单位；完整病例纳入。
- 报告原始 Spearman ρ。
- 共同必需基因按全 2D 细胞系的可用率、效应中位数和依赖比例预设；排除 SCD/VPS72 后提取前 5 个 PC。
- 对两基因在 CRC 内的秩分别回归到全基因中位效应、MAD 和共同必需 PC1–PC5，残差相关定义为调整后的 partial Spearman。
- 用 10,000 次细胞系 bootstrap 给出 CI，并用 10,000 次置换给出 P 值。
- 类器官冻结结果方向为负；只有方向一致、P<0.05 且 CI 不跨 0 才称为复制。正方向为方向性矛盾，不得称为共依赖。

### 3. GSE132465 独立全细胞 CRC 队列

- 在查看目标基因结果前，按“人 CRC、全细胞、有上皮和免疫区室、至少 10 例肿瘤患者、公开 UMI 和作者注释、与 GSE178341 独立”纳入。
- 仅分析肿瘤样本；患者为独立单位。
- T 细胞比例由作者 `Cell_type == T cells` 注释计算。
- 全肿瘤和上皮区室分别构建冻结 8 基因患者级 pseudobulk score；基因缺失或零方差不替换，保留并记录为零贡献。
- 主要检验为全肿瘤 score 与 T 细胞比例的 Spearman ρ；次要检验为上皮 score 的相同相关及绝对相关衰减量。均报告 10,000 次患者 bootstrap/置换。

## 结果分支和写作边界

- 若匹配随机模块解释观察相关，则写“该模块的 T 细胞相关不超出同类免疫特异基因集的零分布”。
- 若观察相关高于随机模块，则只写“冻结模块表现出异常强的 T 谱系耦合”，不能写胞啃事件。
- DepMap 不复制或方向矛盾时，SCD–VPS72 仅保留为类器官平台内探索性负相关。
- GSE132465 只有在患者级全肿瘤相关为正且上皮限制后有预设幅度衰减时，才写跨队列组成追踪复制。
- 三项分析均不得将 RNA 共表达等同于蛋白转移、抗原剃除或胞啃事件。
