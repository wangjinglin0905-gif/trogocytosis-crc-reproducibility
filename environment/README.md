# Frozen software environment

The public release was checked with Python 3.12.13 and R 4.6.1. Directly imported Python packages are pinned in `python-requirements.txt`; direct R package versions are listed in `r-packages.txt`.

R session information generated by the survival and plotting scripts is preserved in:

- `analysis/v8_1_corrections/R_sessionInfo.txt`
- `figures/final/V8_1_changed_figures_R_sessionInfo.txt`

Operating-system locale warnings can occur on Windows if an `en_US.UTF-8`-style locale is unavailable. They did not alter the numerical checks in this release.
